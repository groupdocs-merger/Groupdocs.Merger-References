## IResourceLoadingOptions interface

Controls how resources referenced from outside a document (remote URLs, UNC paths, local files) are loaded while the document is processed.

### Remarks

External resources are not loaded unless the caller allows them: loading a remote or local resource named by an untrusted document can reach internal network addresses, leak Windows credentials through UNC paths, or copy local files into the output. Content carried inside the document (`data:` and `cid:` references, packaged parts) is not external and still loads.
