## LoadOptions.SkipExternalResources property

If true, no external resource is loaded except those matching [`WhitelistedResources`](../whitelistedresources) or allowed by [`ExternalResourceHandler`](../externalresourcehandler). Default value is `true`.

```csharp
public bool SkipExternalResources { get; set; }
```

### Remarks

Loading resources named by an untrusted document can reach internal network addresses, leak Windows credentials through UNC paths, or copy local files into the output. Set to `false` only for trusted input.
