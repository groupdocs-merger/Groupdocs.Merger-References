## SpreadsheetJoinOptions.Mode property

The spreadsheet join mode. The default is Worksheets.

```csharp
public SpreadsheetJoinMode Mode { get; set; }
```

### Remarks

In Rows mode the page numbers select the worksheets of the joined spreadsheet whose rows are appended. Cell values, formulas, cell styles, merged cells and row heights are carried; charts, pictures and other floating objects, pivot tables, tables, conditional formatting and data validation are not. Formulas referring to other worksheets or workbooks may point at different data after joining.
