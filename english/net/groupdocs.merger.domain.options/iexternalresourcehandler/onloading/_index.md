## IExternalResourceHandler.OnLoading method

Called before an external resource is loaded. [`Skipped`](../../externalresourceloadingargs/skipped) arrives set to the decision of [`SkipExternalResources`](../../iresourceloadingoptions/skipexternalresources) and [`WhitelistedResources`](../../iresourceloadingoptions/whitelistedresources); change it to allow or skip the resource, or set [`Data`](../../externalresourceloadingargs/data) to supply its content.

```csharp
public void OnLoading(ExternalResourceLoadingArgs args)
```

| Parameter | Type | Description |
| --- | --- | --- |
| args | ExternalResourceLoadingArgs | The resource being loaded. |

### Remarks

May be called concurrently from worker threads of the document engines. Also called for resources carried inside the document (`data:`, `cid:`); skipping them removes them from the output. If the handler throws, the resource is skipped.
