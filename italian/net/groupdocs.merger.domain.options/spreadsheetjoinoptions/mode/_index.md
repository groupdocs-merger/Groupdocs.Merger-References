## SpreadsheetJoinOptions.Mode property

La modalità di unione del foglio di calcolo. L'impostazione predefinita è Worksheets.

```csharp
public SpreadsheetJoinMode Mode { get; set; }
```

### Osservazioni

In modalità Righe i numeri di pagina selezionano i fogli di lavoro del foglio elettronico unito le cui righe vengono aggiunte. I valori delle celle, le formule, gli stili delle celle, le celle unite e le altezze delle righe vengono mantenuti; grafici, immagini e altri oggetti fluttuanti, tabelle pivot, tabelle, formattazione condizionale e convalida dei dati non lo sono. Le formule che fanno riferimento ad altri fogli di lavoro o cartelle di lavoro possono puntare a dati diversi dopo l'unione.
