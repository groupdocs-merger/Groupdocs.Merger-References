## FileType.XLTM field

Excel Open XML Macro-Enabled Spreadsheet Template (.xltm) rappresenta i file generati da Microsoft Excel come modelli abilitati alle macro. I file XLTM sono simili a XLTX nella struttura, tranne per il fatto che quest'ultimo non supporta la creazione di modelli con macro.
