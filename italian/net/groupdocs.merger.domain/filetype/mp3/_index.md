## FileType.MP3 field

I file con estensione .mp3 sono formati di file audio digitalmente codificati, basati formalmente su MPEG-1 Audio Layer III o MPEG-2 Audio Layer III. Sono stati sviluppati dal Moving Picture Experts Group (MPEG) che utilizza la compressione audio Layer 3. La compressione ottenuta dal formato MP3 è 1/10 della dimensione dei file .WAV o .AIF. Scopri di più su questo formato di file [qui](https://docs.fileformat.com/audio/mp3).
