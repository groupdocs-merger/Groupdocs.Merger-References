## FileType.WAV field

WAV, noto per WAVE (Waveform Audio File Format), è un sottoinsieme della specifica Resource Interchange File Format (RIFF) di Microsoft per la memorizzazione di file audio digitali. Il formato non applica alcuna compressione al flusso di bit e memorizza le registrazioni audio con diverse frequenze di campionamento e bitrate. È stato e rimane uno dei formati standard per i CD audio. Scopri di più su questo formato di file [qui](https://docs.fileformat.com/audio/wav).
