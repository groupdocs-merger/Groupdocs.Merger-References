Il namespace **com.groupdocs.merger.exceptions** fornisce classi per le eccezioni che possono verificarsi durante la manipolazione di un documento.

| Classe | Descrizione |
| --- | --- |
| [FileCorruptedException](../com.groupdocs.merger.exceptions/filecorruptedexception) | L'eccezione che viene generata quando il file specificato non può essere caricato perché sembra essere corrotto. |
| [FileTypeNotSupportedException](../com.groupdocs.merger.exceptions/filetypenotsupportedexception) | L'eccezione che viene generata quando il tipo di file specificato non è supportato. |
| [GroupDocsMergerException](../com.groupdocs.merger.exceptions/groupdocsmergerexception) | Rappresenta gli errori che si verificano durante l'elaborazione del documento. |
| [IncorrectPasswordException](../com.groupdocs.merger.exceptions/incorrectpasswordexception) | L'eccezione che viene generata quando la password specificata è errata. |
| [PasswordRequiredException](../com.groupdocs.merger.exceptions/passwordrequiredexception) | L'eccezione che viene generata quando è necessaria una password per caricare il documento. |
