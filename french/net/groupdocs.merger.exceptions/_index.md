L’espace de noms fournit différentes classes pour les exceptions.

## Classes

| Classe | Description |
| --- | --- |
| [AutoTaggingNotSupportedException](./autotaggingnotsupportedexception) | L'exception qui est levée lorsque le marquage automatique n'a pas pu être appliqué au document spécifié. |
| [FileCorruptedException](./filecorruptedexception) | L'exception qui est levée lorsque le fichier spécifié n'a pas pu être chargé car il semble être corrompu. |
| [FileTypeNotSupportedException](./filetypenotsupportedexception) | L'exception qui est levée lorsque le type de fichier spécifié n'est pas pris en charge. |
| [GroupDocsMergerException](./groupdocsmergerexception) | Représente les erreurs qui surviennent lors du traitement du document. |
| [IncorrectPasswordException](./incorrectpasswordexception) | L'exception qui est levée lorsque le mot de passe spécifié est incorrect. |
| [MissingDependencyException](./missingdependencyexception) | L'exception qui est levée lorsqu'une opération ne peut pas s'exécuter parce qu'une assembly dont elle dépend n'est pas présente dans la sortie de l'application. Le document n'est pas en cause. |
| [PasswordRequiredException](./passwordrequiredexception) | L'exception qui est levée lorsqu'un mot de passe est requis pour charger le document. |
