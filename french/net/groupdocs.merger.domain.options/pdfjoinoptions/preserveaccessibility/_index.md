## PdfJoinOptions.PreserveAccessibility property

Indique si l'accessibilité PDF (structure PDF balisée) doit être préservée lors de la fusion. Lorsque vrai, le document fusionné aura des balises d'accessibilité générées automatiquement pour la conformité PDF/UA. La valeur par défaut est false.

```csharp
public bool PreserveAccessibility { get; set; }
```
