## FileType.PPTX field

La présentation PowerPoint Open XML (.pptx) est un fichier de présentation créé avec l'application populaire Microsoft PowerPoint. Contrairement à la version précédente du format de fichier de présentation PPT qui était binaire, le format PPTX est basé sur le format de présentation Open XML de Microsoft PowerPoint. En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/presentation/pptx).
