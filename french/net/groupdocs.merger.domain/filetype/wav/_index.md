## FileType.WAV field

WAV, connu sous le nom de WAVE (Waveform Audio File Format), est un sous-ensemble de la spécification Resource Interchange File Format (RIFF) de Microsoft pour le stockage de fichiers audio numériques. Le format n’applique aucune compression au flux de bits et stocke les enregistrements audio avec différentes fréquences d’échantillonnage et débits. Il a été et reste l’un des formats standards pour les CD audio. En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/audio/wav).
