## FileType.XLTX field

Les fichiers Excel Open XML Spreadsheet Template (.xltx) sont basés sur les spécifications du format de fichier Office OpenXML. Ils sont utilisés pour créer un fichier modèle standard qui peut être utilisé pour générer des fichiers XLSX présentant les mêmes paramètres que ceux spécifiés dans le fichier XLTX. En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/spreadsheet/xltx).
