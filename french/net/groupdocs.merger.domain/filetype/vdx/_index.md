## FileType.VDX field

Visio Drawing XML File (.vdx) est un dessin ou un diagramme créé dans Microsoft Visio, mais enregistré au format XML avec l'extension .VDX. Un fichier Visio Drawing XML est créé dans le logiciel Visio, développé par Microsoft. En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/image/vdx).
