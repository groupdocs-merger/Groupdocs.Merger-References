## FileType.VSTM field

Visio Macro-Enabled Drawing Template (.vstm) sont des fichiers de modèle créés avec Microsoft Visio qui prennent en charge les macros. Contrairement aux fichiers VSDX, les fichiers créés à partir de modèles VSTM peuvent exécuter des macros développées en code Visual Basic for Applications (VBA). En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/image/vstm).
