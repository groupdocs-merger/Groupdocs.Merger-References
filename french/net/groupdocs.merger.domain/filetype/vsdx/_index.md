## FileType.VSDX field

Visio Drawing (.vsdx) représente le format de fichier Microsoft Visio introduit à partir de Microsoft Office 2013. Il a été développé pour remplacer le format de fichier binaire .VSD, pris en charge par les versions antérieures de Microsoft Visio. En savoir plus sur ce format de fichier [ici](https://docs.fileformat.com/image/vsdx).
