L'espace de noms **com.groupdocs.merger.exceptions** fournit des classes pour les exceptions pouvant survenir lors de la manipulation d’un document.


## Classes

| Classe | Description |
| --- | --- |
| [FileCorruptedException](../com.groupdocs.merger.exceptions/filecorruptedexception) | L'exception qui est levée lorsque le fichier spécifié n'a pas pu être chargé car il semble être corrompu. |
| [FileTypeNotSupportedException](../com.groupdocs.merger.exceptions/filetypenotsupportedexception) | L'exception qui est levée lorsque le type de fichier spécifié n'est pas pris en charge. |
| [GroupDocsMergerException](../com.groupdocs.merger.exceptions/groupdocsmergerexception) | Représente les erreurs qui se produisent lors du traitement du document. |
| [IncorrectPasswordException](../com.groupdocs.merger.exceptions/incorrectpasswordexception) | L'exception qui est levée lorsque le mot de passe spécifié est incorrect. |
| [PasswordRequiredException](../com.groupdocs.merger.exceptions/passwordrequiredexception) | L'exception qui est levée lorsque le mot de passe est requis pour charger le document. |
