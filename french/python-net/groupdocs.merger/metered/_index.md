## Metered class

Gère la licence à la consommation (pay-per-use).

Les licences Metered facturent selon la consommation réelle (généralement les pages ou
documents traités). Définissez la paire de clés publique/privée une fois à
le démarrage de l'application ; le wrapper renvoie l'utilisation au GroupDocs
serveur de licence en arrière-plan.

Le type Metered expose les membres suivants :

### Méthodes
| Méthode | Description |
| :- | :- |
| [get_consumption_credit](/merger/python-net/groupdocs.merger/metered/get_consumption_credit/) | Renvoie le crédit Metered restant pour la clé actuelle. |
| [get_consumption_quantity](/merger/python-net/groupdocs.merger/metered/get_consumption_quantity/) | Renvoie la quantité totale Metered consommée jusqu'à présent. |
| [set_metered_key](/merger/python-net/groupdocs.merger/metered/set_metered_key/#public_key-private_key) | Activez la facturation Metered avec la paire de clés publique/privée fournie. |
