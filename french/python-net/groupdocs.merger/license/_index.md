## License class

Gère la licence de GroupDocs.Merger.

Les builds sous licence débloquent l’ensemble complet de fonctionnalités du wrapper à
runtime. Les builds non sous licence s’exécutent en mode d’évaluation avec la même API
surface mais avec des limites sur la taille de sortie et le contenu filigrané.
