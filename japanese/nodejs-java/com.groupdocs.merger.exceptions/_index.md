**com.groupdocs.merger.exceptions** 名前空間は、ドキュメント操作中に発生し得る例外のクラスを提供します。


## クラス

| クラス | 説明 |
| --- | --- |
| [FileCorruptedException](../com.groupdocs.merger.exceptions/filecorruptedexception) | 指定されたファイルが破損しているように見えるため、読み込めなかったときにスローされる例外です。 |
| [FileTypeNotSupportedException](../com.groupdocs.merger.exceptions/filetypenotsupportedexception) | 指定されたファイルタイプがサポートされていないときにスローされる例外です。 |
| [GroupDocsMergerException](../com.groupdocs.merger.exceptions/groupdocsmergerexception) | ドキュメント処理中に発生するエラーを表します。 |
| [IncorrectPasswordException](../com.groupdocs.merger.exceptions/incorrectpasswordexception) | 指定されたパスワードが正しくないときにスローされる例外です。 |
| [PasswordRequiredException](../com.groupdocs.merger.exceptions/passwordrequiredexception) | ドキュメントの読み込みにパスワードが必要なときにスローされる例外です。 |
