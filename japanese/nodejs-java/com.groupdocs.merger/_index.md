**com.groupdocs.merger** 名前空間は、ドキュメントを結合し、ドキュメント構造を操作できるクラスを提供します（単一ドキュメントを複数に分割、ページの順序変更や置換、ページ向きの変更、ドキュメントのパスワード管理、その他の操作）を、PDF、DOCX/DOC、PPTX/PPT、XLSX/XLS、VSDX/VSD、ODT、ODS、ODP、HTML、EPUB など、幅広いサポート対象のドキュメントタイプで実行できます。


## クラス

| クラス | 説明 |
| --- | --- |
| [Merger](../com.groupdocs.merger/merger) | ドキュメントのマージプロセスを制御するメインクラスを表します。 |
| [MergerSettings](../com.groupdocs.merger/mergersettings) | カスタマイズ設定を定義し、[Merger](../com.groupdocs.merger/merger) の動作を設定します。 |
