この **com.groupdocs.merger** 名前空間は、ドキュメントを結合し、ドキュメント構造を操作できるクラスを提供します（単一ドキュメントを複数に分割、ページの順序変更や置換、ページ向きの変更、ドキュメントのパスワード管理、その他の操作）を、PDF、DOCX/DOC、PPTX/PPT、XLSX/XLS、VSDX/VSD、ODT、ODS、ODP、HTML、EPUB など多数のサポート対象ドキュメントタイプにわたって提供します。


## クラス

| クラス | 説明 |
| --- | --- |
| [Merger](../com.groupdocs.merger/merger) | ドキュメント結合プロセスを制御するメインクラスを表します。 |
| [MergerSettings](../com.groupdocs.merger/mergersettings) | カスタマイズされた [Merger](../com.groupdocs.merger/merger) の動作を定義する設定です。 |
