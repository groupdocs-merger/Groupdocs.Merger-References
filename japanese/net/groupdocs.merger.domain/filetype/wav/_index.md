## FileType.WAV field

WAV は、WAVE（Waveform Audio File Format）として知られ、デジタル音声ファイルを保存するための Microsoft の Resource Interchange File Format（RIFF）仕様のサブセットです。この形式はビットストリームに圧縮を施さず、さまざまなサンプリングレートやビットレートで音声を保存します。オーディオ CD の標準フォーマットの一つとして長らく使用されています。このファイル形式の詳細は[こちら](https://docs.fileformat.com/audio/wav)をご覧ください。
