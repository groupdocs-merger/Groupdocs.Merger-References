## FileType.XLT field

Excel Template File (.xlt) adalah file templat yang dibuat dengan Microsoft Excel, yang merupakan aplikasi spreadsheet yang termasuk dalam paket Microsoft Office. Microsoft Office 97-2003 mendukung pembuatan file XLT baru serta membuka file tersebut. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/spreadsheet/xlt).
