## FileType.WAV field

WAV, yang dikenal sebagai WAVE (Waveform Audio File Format), adalah subset dari spesifikasi Resource Interchange File Format (RIFF) milik Microsoft untuk menyimpan file audio digital. Format ini tidak menerapkan kompresi apa pun pada aliran bit dan menyimpan rekaman audio dengan berbagai laju sampel dan bitrate. Format ini telah menjadi dan tetap menjadi salah satu format standar untuk CD audio. Pelajari lebih lanjut tentang format file ini [di sini](https://docs.fileformat.com/audio/wav).
