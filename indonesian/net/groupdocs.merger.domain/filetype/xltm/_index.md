## FileType.XLTM field

Excel Open XML Macro-Enabled Spreadsheet Template (.xltm) mewakili file yang dihasilkan oleh Microsoft Excel sebagai file templat yang mendukung makro. File XLTM mirip dengan XLTX dalam struktur, kecuali bahwa yang terakhir tidak mendukung pembuatan file templat dengan makro.
