Namespace **com.groupdocs.merger.exceptions** menyediakan kelas untuk pengecualian yang dapat terjadi saat bekerja dengan dokumen.


## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [FileCorruptedException](../com.groupdocs.merger.exceptions/filecorruptedexception) | Pengecualian yang dilemparkan ketika file yang ditentukan tidak dapat dimuat karena tampaknya rusak. |
| [FileTypeNotSupportedException](../com.groupdocs.merger.exceptions/filetypenotsupportedexception) | Pengecualian yang dilemparkan ketika tipe file yang ditentukan tidak didukung. |
| [GroupDocsMergerException](../com.groupdocs.merger.exceptions/groupdocsmergerexception) | Mewakili kesalahan yang terjadi selama pemrosesan dokumen. |
| [IncorrectPasswordException](../com.groupdocs.merger.exceptions/incorrectpasswordexception) | Pengecualian yang dilemparkan ketika kata sandi yang ditentukan tidak benar. |
| [PasswordRequiredException](../com.groupdocs.merger.exceptions/passwordrequiredexception) | Pengecualian yang dilemparkan ketika kata sandi diperlukan untuk memuat dokumen. |
