Пространство имен **com.groupdocs.merger.exceptions** предоставляет классы для исключений, которые могут возникнуть при работе с документом.


## Классы

| Класс | Описание |
| --- | --- |
| [FileCorruptedException](../com.groupdocs.merger.exceptions/filecorruptedexception) | Исключение, которое выбрасывается, когда указанный файл не может быть загружен, потому что он кажется повреждённым. |
| [FileTypeNotSupportedException](../com.groupdocs.merger.exceptions/filetypenotsupportedexception) | Исключение, которое выбрасывается, когда указанный тип файла не поддерживается. |
| [GroupDocsMergerException](../com.groupdocs.merger.exceptions/groupdocsmergerexception) | Представляет ошибки, которые возникают во время обработки документа. |
| [IncorrectPasswordException](../com.groupdocs.merger.exceptions/incorrectpasswordexception) | Исключение, которое выбрасывается, когда указанный пароль неверен. |
| [PasswordRequiredException](../com.groupdocs.merger.exceptions/passwordrequiredexception) | Исключение, которое выбрасывается, когда для загрузки документа требуется пароль. |
