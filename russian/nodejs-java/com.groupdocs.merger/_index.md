Пространство имён **com.groupdocs.merger** предоставляет классы, позволяющие объединять документы и управлять структурой документа (разделять один документ на несколько, переупорядочивать или заменять страницы документа, менять ориентацию страниц, управлять паролем документа и выполнять другие манипуляции) для широкого спектра поддерживаемых типов файлов — PDF, DOCX/DOC, PPTX/PPT, XLSX/XLS, VSDX/VSD, ODT, ODS, ODP, HTML, EPUB и многих других.

| Построитель PageInfo для получения коллекции страниц из документов. | Описание |
| --- | --- |
| [Merger](../com.groupdocs.merger/merger) | Представляет основной класс, контролирующий процесс объединения документов. |
| [MergerSettings](../com.groupdocs.merger/mergersettings) | Определяет параметры для настройки поведения [Merger](../com.groupdocs.merger/merger). |
