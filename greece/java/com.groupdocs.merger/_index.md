Το **com.groupdocs.merger** namespace παρέχει κλάσεις που σας επιτρέπουν να συγχωνεύετε έγγραφα και να διαχειρίζεστε τη δομή των εγγράφων (διαχωρισμός ενός εγγράφου σε πολλά έγγραφα, αναδιάταξη ή αντικατάσταση σελίδων εγγράφου, αλλαγή προσανατολισμού σελίδας, διαχείριση κωδικού πρόσβασης εγγράφου και άλλες επεμβάσεις) σε ευρύ φάσμα υποστηριζόμενων τύπων εγγράφων - PDF, DOCX/DOC, PPTX/PPT, XLSX/XLS, VSDX/VSD, ODT, ODS, ODP, HTML, EPUB και πολλά άλλα.

| Κλάση | Περιγραφή |
| --- | --- |
| [Merger](../com.groupdocs.merger/merger) | Αντιπροσωπεύει την κύρια κλάση που ελέγχει τη διαδικασία συγχώνευσης εγγράφων. |
| [MergerSettings](../com.groupdocs.merger/mergersettings) | Ορίζει ρυθμίσεις για την προσαρμογή της συμπεριφοράς του [Merger](../com.groupdocs.merger/merger). |
