## FileType.WAV field

Το WAV, γνωστό για το WAVE (Waveform Audio File Format), είναι ένα υποσύνολο της προδιαγραφής Resource Interchange File Format (RIFF) της Microsoft για την αποθήκευση ψηφιακών αρχείων ήχου. Η μορφή δεν εφαρμόζει καμία συμπίεση στο bitstream και αποθηκεύει τις ηχογραφήσεις με διαφορετικούς ρυθμούς δειγματοληψίας και bitrate. Είναι και ήταν ένα από τα πρότυπα μορφές για CD ήχου. Μάθετε περισσότερα για αυτή τη μορφή αρχείου [εδώ](https://docs.fileformat.com/audio/wav).

public static readonly FileType WAV;
