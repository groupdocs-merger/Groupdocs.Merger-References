## FileType.PPTX field

Το PowerPoint Open XML Presentation (.pptx) είναι ένα αρχείο παρουσίασης που δημιουργείται με τη δημοφιλή εφαρμογή Microsoft PowerPoint. Σε αντίθεση με την προηγούμενη έκδοση του μορφότυπου αρχείου παρουσίασης PPT που ήταν δυαδική, το μορφότυπο PPTX βασίζεται στο ανοιχτό XML μορφότυπο παρουσίασης του Microsoft PowerPoint. Μάθετε περισσότερα για αυτό το μορφότυπο αρχείου [εδώ](https://docs.fileformat.com/presentation/pptx).

public static readonly FileType PPTX;
