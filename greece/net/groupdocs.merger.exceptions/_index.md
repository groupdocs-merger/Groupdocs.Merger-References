Ο ονοματοχώρος παρέχει διαφορετικές κλάσεις για εξαιρέσεις.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [AutoTaggingNotSupportedException](./autotaggingnotsupportedexception) | Η εξαίρεση που προκαλείται όταν η αυτόματη ετικετοποίηση δεν μπορεί να εφαρμοστεί στο καθορισμένο έγγραφο. |
| [FileCorruptedException](./filecorruptedexception) | Η εξαίρεση που προκαλείται όταν το καθορισμένο αρχείο δεν μπορεί να φορτωθεί επειδή φαίνεται να είναι κατεστραμμένο. |
| [FileTypeNotSupportedException](./filetypenotsupportedexception) | Η εξαίρεση που προκαλείται όταν ο καθορισμένος τύπος αρχείου δεν υποστηρίζεται. |
| [GroupDocsMergerException](./groupdocsmergerexception) | Αντιπροσωπεύει σφάλματα που συμβαίνουν κατά την επεξεργασία εγγράφων. |
| [IncorrectPasswordException](./incorrectpasswordexception) | Η εξαίρεση που προκαλείται όταν ο καθορισμένος κωδικός πρόσβασης είναι λανθασμένος. |
| [MissingDependencyException](./missingdependencyexception) | Η εξαίρεση που προκαλείται όταν μια λειτουργία δεν μπορεί να εκτελεστεί επειδή μια εξαρτημένη συναρμολόγηση δεν υπάρχει στην έξοδο της εφαρμογής. Το έγγραφο δεν είναι υπεύθυνο. |
| [PasswordRequiredException](./passwordrequiredexception) | Η εξαίρεση που προκαλείται όταν απαιτείται κωδικός πρόσβασης για τη φόρτωση του εγγράφου. |
