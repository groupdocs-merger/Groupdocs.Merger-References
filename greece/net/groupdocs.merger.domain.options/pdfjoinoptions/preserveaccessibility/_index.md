## PdfJoinOptions.PreserveAccessibility property

Δείχνει αν η προσβασιμότητα PDF (δομή PDF με ετικέτες) πρέπει να διατηρηθεί κατά τη συγχώνευση. Όταν είναι true, το συγχωνευμένο έγγραφο θα έχει αυτόματα δημιουργημένες ετικέτες προσβασιμότητας για συμμόρφωση με PDF/UA. Η προεπιλογή είναι false.

```csharp
public bool PreserveAccessibility { get; set; }
```
