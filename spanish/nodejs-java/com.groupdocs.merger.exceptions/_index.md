El espacio de nombres **com.groupdocs.merger.exceptions** proporciona clases para excepciones que pueden ocurrir al trabajar con un documento.

| Clase | Descripción |
| --- | --- |

| [FileTypeNotSupportedException](../com.groupdocs.merger.exceptions/filetypenotsupportedexception) | La excepción que se lanza cuando el tipo de archivo especificado no es compatible. |
| [GroupDocsMergerException](../com.groupdocs.merger.exceptions/groupdocsmergerexception) | Representa errores que ocurren durante el procesamiento de documentos. |
| [IncorrectPasswordException](../com.groupdocs.merger.exceptions/incorrectpasswordexception) | La excepción que se lanza cuando la contraseña especificada es incorrecta. |
| [PasswordRequiredException](../com.groupdocs.merger.exceptions/passwordrequiredexception) | La excepción que se lanza cuando se requiere una contraseña para cargar el documento. |
