**com.groupdocs.merger** 命名空间提供的类允许您合并文档并操作文档结构（将单个文档拆分为多个文档、重新排序或替换文档页面、更改页面方向、管理文档密码以及执行其他操作），适用于广泛的支持文档类型 - PDF、DOCX/DOC、PPTX/PPT、XLSX/XLS、VSDX/VSD、ODT、ODS、ODP、HTML、EPUB 等等。
