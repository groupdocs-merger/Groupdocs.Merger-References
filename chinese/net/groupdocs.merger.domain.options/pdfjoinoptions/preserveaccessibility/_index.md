## PdfJoinOptions.PreserveAccessibility property

指示在合并期间是否应保留 PDF 可访问性（标记的 PDF 结构）。如果为 true，合并后的文档将具有自动生成的可访问性标签，以符合 PDF/UA 标准。默认值为 false。

public bool PreserveAccessibility { get; set; }
