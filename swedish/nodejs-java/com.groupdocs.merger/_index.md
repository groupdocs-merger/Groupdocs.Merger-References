Namnområdet **com.groupdocs.merger** tillhandahåller klasser som låter dig sammanfoga dokument och manipulera dokumentstruktur (dela ett enda dokument i flera dokument, omordna eller ersätta dokumentsidor, ändra sidorientering, hantera dokumentlösenord och utföra andra manipulationer) över ett brett spektrum av stödda dokumenttyper – PDF, DOCX/DOC, PPTX/PPT, XLSX/XLS, VSDX/VSD, ODT, ODS, ODP, HTML, EPUB och många fler.


## Klasser

| Klass | Beskrivning |
| --- | --- |
| [Merger](../com.groupdocs.merger/merger) | Representerar huvudklassen som styr dokumentsammanfogningsprocessen. |
| [MergerSettings](../com.groupdocs.merger/mergersettings) | Definierar inställningar för att anpassa [Merger](../com.groupdocs.merger/merger)-beteendet. |
