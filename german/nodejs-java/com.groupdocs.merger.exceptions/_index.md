Der **com.groupdocs.merger.exceptions** namespace stellt Klassen für Ausnahmen bereit, die bei der Arbeit mit einem Dokument auftreten können.


## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [FileCorruptedException](../com.groupdocs.merger.exceptions/filecorruptedexception) | Die Ausnahme, die ausgelöst wird, wenn die angegebene Datei nicht geladen werden konnte, weil sie beschädigt zu sein scheint. |
| [FileTypeNotSupportedException](../com.groupdocs.merger.exceptions/filetypenotsupportedexception) | Die Ausnahme, die ausgelöst wird, wenn der angegebene Dateityp nicht unterstützt wird. |
| [GroupDocsMergerException](../com.groupdocs.merger.exceptions/groupdocsmergerexception) | Stellt Fehler dar, die bei der Dokumentenverarbeitung auftreten. |
| [IncorrectPasswordException](../com.groupdocs.merger.exceptions/incorrectpasswordexception) | Die Ausnahme, die ausgelöst wird, wenn das angegebene Passwort falsch ist. |
| [PasswordRequiredException](../com.groupdocs.merger.exceptions/passwordrequiredexception) | Die Ausnahme, die ausgelöst wird, wenn zum Laden des Dokuments ein Passwort erforderlich ist. |
