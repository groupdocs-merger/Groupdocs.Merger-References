## SpreadsheetJoinOptions.Mode property

Der Tabellenblatt‑Zusammenführungsmodus. Der Standardwert ist Worksheets.

```csharp
public SpreadsheetJoinMode Mode { get; set; }
```

### Bemerkungen

Im Zeilen‑Modus wählen die Seitenzahlen die Arbeitsblätter der zusammengeführten Tabelle aus, deren Zeilen angehängt werden. Zellwerte, Formeln, Zellstile, zusammengeführte Zellen und Zeilenhöhen werden übernommen; Diagramme, Bilder und andere schwebende Objekte, Pivot‑Tabellen, Tabellen, bedingte Formatierung und Datenvalidierung nicht. Formeln, die sich auf andere Arbeitsblätter oder Arbeitsmappen beziehen, können nach dem Zusammenführen auf andere Daten verweisen.
