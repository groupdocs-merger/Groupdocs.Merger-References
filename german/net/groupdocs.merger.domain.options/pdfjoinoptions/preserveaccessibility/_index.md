## PdfJoinOptions.PreserveAccessibility property

Gibt an, ob die PDF-Barrierefreiheit (getaggte PDF-Struktur) beim Zusammenführen erhalten bleiben soll. Wenn true, enthält das zusammengeführte Dokument automatisch generierte Barrierefreiheits‑Tags für die PDF/UA-Konformität. Standard ist false.

public bool PreserveAccessibility { get; set; }
