## FileType.WAV field

WAV, bekannt für WAVE (Waveform Audio File Format), ist ein Teil der Resource Interchange File Format (RIFF)-Spezifikation von Microsoft zur Speicherung digitaler Audiodateien. Das Format wendet keine Kompression auf den Bitstrom an und speichert Audioaufnahmen mit unterschiedlichen Abtastraten und Bitraten. Es war und ist eines der Standardformate für Audio‑CDs. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://docs.fileformat.com/audio/wav).
