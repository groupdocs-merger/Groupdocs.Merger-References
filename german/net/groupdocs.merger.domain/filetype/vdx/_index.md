## FileType.VDX field

Visio Drawing XML File (.vdx) ist eine Zeichnung oder ein Diagramm, das in Microsoft Visio erstellt, aber im XML-Format mit der Erweiterung .VDX gespeichert wurde. Eine Visio Drawing XML-Datei wird in der Visio-Software erstellt, die von Microsoft entwickelt wurde. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://docs.fileformat.com/image/vdx).
