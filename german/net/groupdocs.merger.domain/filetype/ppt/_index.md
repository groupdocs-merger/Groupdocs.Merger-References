## FileType.PPT field

PowerPoint-Präsentation (.ppt) stellt eine PowerPoint-Datei dar, die aus einer Sammlung von Folien für die Anzeige als Diashow besteht. Sie gibt das binäre Dateiformat an, das von Microsoft PowerPoint 97-2003 verwendet wird. Weitere Informationen zu diesem Dateiformat finden Sie [hier](https://docs.fileformat.com/presentation/ppt).
